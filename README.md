# Venta de Guitarras

Aplicación web desarrollada con React, TypeScript y Vite que simula una tienda de guitarras en línea. Permite explorar un catálogo de productos, agregar artículos al carrito de compras, modificar cantidades y calcular automáticamente el total de la compra.

## Tecnologías utilizadas

- React
- TypeScript
- Vite
- useReducer
- CSS3
- Git y GitHub Pages

## Funcionalidades

- Visualización de catálogo de guitarras.
- Agregar productos al carrito.
- Incrementar y disminuir cantidades.
- Eliminar productos del carrito.
- Vaciar carrito de compras.
- Cálculo automático del total.
- Persistencia del estado mediante React.
